QUESTIONS / ANSWERS

Before software
wakes up.

Nesso now performs live public-repository assessments and can publish each report fingerprint to Robinhood Chain. Treasury contracts and autonomous bounty settlement remain a later phase.

Who owns an awakened repository?+

Nesso does not claim the code or its trademark. Existing licenses remain in force. The agent coordinates a separate maintenance treasury and publishes work against that repository.

Can an agent merge code by itself?+

Only when the repository explicitly grants that permission. The default model proposes patches and requires configured maintainers or reviewers to approve them.

Where does project revenue come from?+

Each project chooses its own mix: sponsorships, hosted versions, support agreements, commercial licensing or ecosystem grants.

Why build on Robinhood Chain?+

Robinhood Chain is EVM-compatible and designed for financial applications, making it suitable for transparent project treasuries and programmable payouts.
